Sentinel stores configuration, logs, backups, node identities and AI conversation history on the PC. The browser stores language and theme preferences. The dashboard uses a local session when administrator authentication is enabled.

Ollama processes AI requests on the device. Chat can use project data visible in the dashboard and relevant source excerpts. Avoid entering credentials in conversations. AI Chat can clear its local history. Inspect the installation folder for retained logs and backups.

When Funnel is enabled, Tailscale handles the public connection and the site becomes accessible at the assigned address. The site operator chooses published content and handles visitor data. Downloads, updates and configured external notifications can contact their respective providers.

HTML documentation offers browser-based translation. The browser controls supported languages and language-pack downloads. Screenshots keep their original language.
